# KOHO Visual — Architectural Visualization Portfolio

A modern, minimalist portfolio site built with Next.js 15 for architectural visualization studios.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy

Push to GitHub and connect to Vercel — it will auto-deploy.

## Add Projects

Edit `src/data/projects.json` and place images in `public/projects/`.

See `ADMIN-GUIDE.md` for full instructions.
